## 4.1 ARCHETYPE PHILOSOPHY

Each class in Ragnarok Online has a **distinctive visual identity** that players recognize instantly.  
This recognition comes from the combination of:
- Silhouette (hat, armor bulk, weapon shape)
- Color family (red/metal for warriors, blue/purple for mages, etc.)
- Posture and bearing (upright vs relaxed vs aggressive)
- Equipment signature (staff, bow, blades, hammer)

When creating original characters, **start with the archetype first**, then customize within it.

## 4.2 WARRIOR ARCHETYPES

### Swordsman
```
VISUAL IDENTITY: Straightforward fighter in starter plate/chainmail
SILHOUETTE DEFINING ELEMENT: Medium shoulder armor, sword at side
BODY BUILD: Standard male/female, slight muscle
HEAD: Helmet or exposed hair, determined expression

COLOR PALETTE:
  Primary:   Steel grey / iron (#6B6B6B)
  Secondary: Brown leather (#8B5E3C)
  Accent:    Belt/buckle gold (#C8A951)

WEAPON SIGNATURE: One-handed sword + shield OR two-handed sword
SPECIAL VISUAL: Often the "entry point" look — balanced, readable
```

### Knight / Lord Knight
```
VISUAL IDENTITY: Heavy plate warrior, commanding presence
SILHOUETTE DEFINING ELEMENT: Broad pauldrons, full helmet, sword
BODY BUILD: Heaviest build — plate expands silhouette by ~30%
HEAD: Full-face helmet or ornate helm

COLOR PALETTE:
  Primary:   Polished steel (#A8A8A8) / dark iron (#4A4A4A)
  Secondary: Royal blue cape (#1A3A6B) or crimson (#8B1A1A)
  Accent:    Gold trim (#C8A951), chain detail

WEAPON SIGNATURE: Long sword, two-handed spear, or giant axe
SPECIAL VISUAL: Grand pauldron width — widest silhouette of any class
```

### Crusader / Paladin
```
VISUAL IDENTITY: Holy warrior combining faith and arms
SILHOUETTE DEFINING ELEMENT: Ornate holy shield, cross motifs
COLOR PALETTE:
  Primary:   Holy silver (#D4D4D4), white (#F0EDE0)
  Secondary: Royal blue (#1E3A5F), gold cross (#C8A951)
  Accent:    Divine glow on shield (optional emissive)

WEAPON SIGNATURE: Sword + large decorated shield with holy symbol
SPECIAL VISUAL: Shield is the class identity element — make it prominent
```

## 4.3 MAGE ARCHETYPES

### Mage
```
VISUAL IDENTITY: Scholarly novice caster in robes + signature hat
SILHOUETTE DEFINING ELEMENT: Distinctive wide-brimmed or tall wizard hat
BODY BUILD: Slim — robes conceal body, staff extends reach
HEAD: Large iconic hat (often the most recognizable element)

COLOR PALETTE:
  Primary:   Purple robe (#4A2060) / dark blue (#1A1A5F)
  Secondary: White/grey staff (#E0E0E0)
  Accent:    Gold or silver magical trim

WEAPON SIGNATURE: Staff or wand (held at side or raised)
SPECIAL VISUAL: Hat is the CLASS ICON — unique shape per subtype
```

### Wizard / High Wizard
```
VISUAL IDENTITY: Powerful arcane master in elaborate robes
COLOR PALETTE:
  Primary:   Deep purple (#2D0040) / midnight blue (#0A0A3D)
  Secondary: Arcane gold (#FFD700) magical lines on robe
  Accent:    Eye-glow or magical aura (subtle emissive)

WEAPON SIGNATURE: Elaborate magical staff (ornate tip, crystal)
SPECIAL VISUAL: Hat grows more elaborate — High Wizard hat is iconic
```

### Sage / Professor
```
VISUAL IDENTITY: Intellectual scholar with scholarly accessories
COLOR PALETTE:
  Primary:   Scholar grey (#6B6B8B) / dusty blue (#4A5080)
  Secondary: Parchment (#F0E6C8) book pages, leather tome
  Accent:    Ink blue (#1A2080) detailing
WEAPON SIGNATURE: Book + rod combination
```

## 4.4 ARCHER ARCHETYPES

### Archer
```
VISUAL IDENTITY: Ranger in leather, agile and prepared
SILHOUETTE DEFINING ELEMENT: Bow shape visible over shoulder or in hand
BODY BUILD: Athletic, lean — balanced arm/leg build
HEAD: Leather cap, earrings, alert expression

COLOR PALETTE:
  Primary:   Forest green (#2D5A1B) / leather brown (#7A4A28)
  Secondary: Cream/off-white (#F0E8D0) shirt
  Accent:    Arrow fletching orange/red

WEAPON SIGNATURE: Recurve bow (the class visual icon)
SPECIAL VISUAL: Quiver on back adds secondary silhouette element
```

### Hunter / Sniper
```
VISUAL IDENTITY: Expert marksman, precision-focused
COLOR PALETTE:
  Primary:   Dark green (#1A3D0F) / hunter's brown (#5C3A1E)
  Secondary: Tactical grey (#6B6B6B) for equipment
WEAPON SIGNATURE: Larger longbow, crossbow, or rifle (Gunslinger path)
SPECIAL VISUAL: Falcon/hawk companion (Hunter class unique icon)
```

### Bard / Minstrel
```
VISUAL IDENTITY: Performer-fighter with musical instrument weapon
COLOR PALETTE:
  Primary:   Warm festive red (#8B1A1A) or performer blue (#1A3A8B)
  Secondary: Gold trim, theatrical colors
WEAPON SIGNATURE: Musical instrument (guitar/lute) used as weapon
SPECIAL VISUAL: Flowing performer garments, theatrical hat
```

## 4.5 THIEF ARCHETYPES

### Thief
```
VISUAL IDENTITY: Quick, shadowy, asymmetric design
SILHOUETTE DEFINING ELEMENT: Distinctive askew hat, lean build
BODY BUILD: Lean and angular — built for speed
HEAD: Characteristic tilted/angled hat (the thief visual signature)

COLOR PALETTE:
  Primary:   Shadow black (#1A1A1A) / dark navy (#0A0A2D)
  Secondary: Purple undergarment (#3D1A5F)
  Accent:    Belt daggers, subtle red accent

WEAPON SIGNATURE: Dagger(s) — often dual-wielded
SPECIAL VISUAL: Asymmetric hat is the most recognizable thief element
```

### Assassin / Assassin Cross
```
VISUAL IDENTITY: Silent killer in layered dark garments
COLOR PALETTE:
  Primary:   Charcoal (#2A2A2A) / purple-black (#1A0028)
  Secondary: Poison green (#2D5C1A) accent (Assassin Cross)
WEAPON SIGNATURE: Katar (H-shaped blade) — unique weapon silhouette
SPECIAL VISUAL: Katar shape is iconic — make it prominent in hand
```

### Rogue / Stalker
```
VISUAL IDENTITY: Cunning schemer, cape-wearing operative
COLOR PALETTE:
  Primary:   Deep teal (#0A3D3D) / forest shadow (#1A2D1A)
  Secondary: Brown leather trim, cream highlights
WEAPON SIGNATURE: Daggers + bow (versatile)
```

## 4.6 ACOLYTE ARCHETYPES

### Acolyte
```
VISUAL IDENTITY: Holy novice with staff and simple robes
SILHOUETTE DEFINING ELEMENT: Simple staff + flowing robe
BODY BUILD: Standard, often slight/gentle appearance
HEAD: Simple circlet or no headgear — open, earnest expression

COLOR PALETTE:
  Primary:   Holy white (#F5F0E8) / pale blue-white (#E8EDF5)
  Secondary: Light blue or gold divine trim
  Accent:    Cross or holy symbol gold (#C8A951)

WEAPON SIGNATURE: Mace or staff (held upright, not aggressive)
SPECIAL VISUAL: Robe shape dominates — elegant flowing silhouette
```

### Priest / High Priest
```
VISUAL IDENTITY: Authoritative holy figure in elaborate vestments
COLOR PALETTE:
  Primary:   Pure white (#FFFFFF) / ivory (#FFFFF0)
  Secondary: Divine gold (#FFD700) for trim and cross motifs
  Accent:    Holy blue (#1A3A6B) under-robe
WEAPON SIGNATURE: Ornate mace + large cross/holy symbol
SPECIAL VISUAL: Elaborate hat/miter — taller than acolyte
```

### Monk / Champion
```
VISUAL IDENTITY: Martial artist with exposed arms showing power
COLOR PALETTE:
  Primary:   Saffron orange (#CC7700) / white (#FFFFFF)
  Secondary: Bare skin arms (brown to tan skin tone)
WEAPON SIGNATURE: Bare fists or chain-wrapped fists
SPECIAL VISUAL: Exposed arms are the class identity — no sleeves
```

## 4.10 ARCHETYPE DECISION TREE (ORIGINAL CHARACTER)

```
START: What is the character's PRIMARY role?

COMBAT?
├── Heavy armored → WARRIOR branch (Knight/Crusader)
├── Light/agile → THIEF branch (Assassin/Rogue)
├── Ranged → ARCHER branch (Hunter/Sniper)
└── Unarmed → MONK branch

MAGIC?
├── Offensive → MAGE branch (Wizard)
├── Supportive → ACOLYTE branch (Priest)
└── Utility/Scholar → SAGE/ALCHEMIST branch

ECONOMIC?
└── MERCHANT branch (Blacksmith/Alchemist/Creator)

SPECIALTY?
├── Performer → BARD/DANCER branch
├── Mystic → SOUL LINKER branch
├── Martial arts → TAEKWON branch
└── Eastern assassin → NINJA branch

THEN:
1. Select body proportions from archetype table (Section 4.2–4.9)
2. Apply color palette from archetype
3. Define the SILHOUETTE DEFINING ELEMENT
4. Confirm weapon signature
5. Build proportion blueprint (see: ../references/02_character_proportion_system.md)
```

## 4.11 NPC AND MONSTER ARCHETYPES

### Generic NPC Categories
```
TOWN NPC: Bright casual colors, accessible expression, non-threatening build
QUEST NPC: Distinctive color to stand out from background
MERCHANT NPC: Shop apron/display, friendly readability
GUARD NPC: Armor similar to Swordsman but without player-class markers
```

### Monster Visual Categories
```
UNDEAD: Desaturated, grey-green skin, torn garments, hollow eyes
INSECT: Exoskeleton plates, antenna, compound eye suggestion, vivid colors
BEAST: Fur texture suggestion, natural colors (brown/grey/black), fangs
MAGICAL: Glowing elements, unnatural colors (void purple, arcane blue)
PLANT: Green palette, organic shapes, vine/petal motifs
DEMON: Red/dark palette, horn, wing, unnatural eye color
HUMANOID MONSTER: Exaggerated features of human archetype (orc = bulkier swordsman)
```

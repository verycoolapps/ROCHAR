**NEVER:**
- Present generic anime characters as authentic RO recreations
- Randomize proportions without reference analysis
- Use unnecessary realistic PBR materials
- Produce fake shader implementations that cannot compile
- Invent undocumented file format specifications
- Claim automatic rigging success without validation
- Confuse shader snippets with working rendering pipelines
- Confuse generated images with actual 3D models

**ALWAYS:**
- Analyze silhouette before beginning any modeling
- Validate GLSL uniform/attribute interfaces match between vertex and fragment
- Preserve classic RO aesthetic over modern PBR temptation
- Distinguish authorized recreations from proprietary assets
- Identify assumptions clearly and explicitly
